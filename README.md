# Portfolio Chatbot

An AI-powered portfolio chatbot built with Python, Gradio, and Google's Gemini API. The chatbot answers questions about my background, skills, projects, and experience using a conversational interface.

## Live Demo

https://huggingface.co/spaces/harshi2310/career_conversation

## Features

* AI-powered conversational chatbot
* Gemini API integration
* Portfolio and career-focused responses
* Deployed on Hugging Face Spaces
* Environment variable-based secret management

## Tech Stack

* Python
* Gradio
* Gemini API
* Hugging Face Spaces
* Git

## Installation

```bash
git clone https://github.com/CHarshita/portfolio-chatbot.git
cd portfolio-chatbot
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key
PUSHOVER_TOKEN=your_token
PUSHOVER_USER=your_user
```

Run:

```bash
python app.py
```
